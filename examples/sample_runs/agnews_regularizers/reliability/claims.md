# Claim audit: conclusions beyond the evidence

One judge, the same instructions for every paper, pipeline marks removed. A claim counts as beyond the evidence when the judge calls it overstated, unsupported or contradicted. The judge is a model of the same family as the reviewers that approved the staged paper's statements, so agreement between them is not independent confirmation. Claims within a paper are not independent, so the intervals are too narrow.
