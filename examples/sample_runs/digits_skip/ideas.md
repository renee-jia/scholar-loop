## 1. Pre-registered paired equivalence test: zero-parameter identity skip vs. weight-identical plain MLP on sklearn-digits  ✅ selected

This is the grounded version of the author's two-arm idea. Both arms share one architecture: an input projection 64→W (W = hidden = 128), then two hidden blocks f_l(h) = ReLU(Linear_{W→W}(h)), then a 10-way head. The residual arm computes h_{l+1} = h_l + f_l(h_l). The plain arm computes h_{l+1} = f_l(h_l). The identity skip has no weights, so the two arms have exactly the same parameter tensors by construction and need no width compensation. To isolate the path, each seed gives both arms bit-identical initial weights, the same minibatch order and the same number of optimizer steps. The only difference left is the '+ h_l' term. The primary contrast is pre-registered as a TOST equivalence test on the paired difference in final val_top1_err, with margin ±0.5 pp. That makes a null decisive rather than inconclusive. The 'trains differently' confound is handled in two ways. Each arm gets its own lr, picked on an inner split carved from the training data only. As a robustness check, both arms also run at a shared lr grid. Step-resolved validation curves separate speed from final error.
